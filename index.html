장애 대응 2024.08 Oracle 프로시저 자동신청 배치

컬럼 하나를 추가했다가 자동신청 배치가 5일간 멈춘 일

기능 개발을 위해 복지카드 비용신청 테이블에 NOT NULL 컬럼을 하나 추가했습니다. 이 테이블에 데이터를 넣는 프로시저까지는 확인하지 못한 채, 기존 기능에는 영향이 없을 거라고 판단했습니다.

원인
  • 직접 원인: 자동신청 프로시저는 컬럼 이름을 적지 않고 모든 컬럼에 한꺼번에 값을 넣는 방식이었습니다. 새 컬럼에는 빈 값이 들어가 NOT NULL 조건에 걸렸고, 배치가 매일 실패했습니다.
  • 늦게 안 이유: 배치 결과 로그를 바로 확인하지 못해 5일이 지나서야 알게 됐습니다.
  • 근본 원인: 이 배치와 프로시저에 대한 인수인계가 전혀 없었고, 소스 구조도 파악하기 어려운 상태였습니다.
대응
  • 멈춰 있던 5일치 매출을 수기로 신청 처리했습니다. 이때 직접 신청하기로 설정한 고객의 건까지 함께 처리되는 문제가 생겼습니다.
  • 잘못 처리된 건은 고객사별로 화면의 반려 기능을 써서 되돌렸습니다. DB 값만 바꾸면 차감된 포인트가 복구되지 않기 때문입니다.
  • 작업 전에 대상 데이터를 백업해 두어, 처리 도중 데이터가 바뀌었을 때도 맞춰서 보정할 수 있었습니다.
남긴 것
  • 테이블 구조를 바꾸기 전에, 그 테이블을 쓰는 프로시저와 배치를 먼저 찾는다.
  • 운영 중인 테이블에 NOT NULL 컬럼은 함부로 추가하지 않는다.
  • 배치를 바꾼 뒤에는 수행 결과 로그를 바로 확인한다.

개발 2023.11 – 2024 건강검진 정산 첫 프로젝트

첫 프로젝트에서 맡은 건강검진 운영비 정산 배치와 선입금 차감 로직

2023년 11월 입사 후 처음 배정받은 프로젝트입니다. 처음에는 고객사 건강검진 대행 운영비를 정산하는 화면의 조회·수정 기능만 맡았습니다. 기존 개발자가 PM으로 옮기면서 운영비 정산 배치를 이어받았고, 중간에 검진비 선입금 차감 로직까지 개발했습니다.

만든 것
  • 운영비 정산 배치: 고객사별 운영비 기준(청구 주기, 금액, 청구 단위 등)을 읽어 이번 달 청구 대상인지 판단하고, 이미 만든 정산 내역과 비교해 새로 만들거나 고칩니다.
  • 선입금 차감: 고객사가 미리 낸 검진비에서 정산 건마다 금액을 차감합니다. 한 선입금의 잔액이 모자라면 다음 선입금으로 넘어가 남은 금액을 마저 차감합니다.
검증
  • 금액을 다루는 로직이라, 두 로직 모두 플로우 차트를 먼저 그려 PM에게 검증받은 뒤 개발했습니다.
  • 배치는 청구 주기, 청구 단위, 금액 단위 같은 기준을 하나씩 바꿔 가며 엑셀로 테스트 케이스를 만들고, 예상 결과와 실제 결과를 하나하나 대조했습니다. 이 과정에서 기준과 기존 정산 내역을 비교하는 로직의 오류를 찾아 고쳤습니다.
  • 로컬에서는 IntelliJ 디버거로 단계마다 값을 직접 확인했습니다.
결과
오픈 후 정산 오류가 거의 없었습니다.
연동 2025.07 – 09 SAML 2.0 Canvas LMS

인증하는 척만 하던 Canvas 연동을 실제 SAML SSO로 완성

회사가 새 LMS 포털을 만들면서 Canvas와 로그인을 연동해야 했습니다. 기존 코드는 Canvas 쪽 인증 부분을 주석 처리해 두고, 실제 인증 없이 로그인된 것처럼 동작하고 있었습니다. 다른 개발자가 만들던 SSO 연동 모듈을 이어받아 실제로 인증이 되도록 완성했습니다.

정리
먼저 인증 흐름을 정리했습니다. 포털은 사용자를 인증하는 쪽(IdP), Canvas는 그 결과를 믿고 로그인시키는 쪽(SP)으로 역할을 정했습니다. SAML 표준과 Canvas 설정을 GPT와 함께 하나씩 대조하며 요청부터 로그인까지 순서를 확인했습니다.
구현
  • Canvas가 받아들이는 인증 응답 XML 양식을 확정해 템플릿으로 만들었습니다.
  • OpenSSL로 인증서와 개인키를 발급하고, 응답 XML에 전자서명을 넣었습니다.
  • Canvas에 인증서를 등록해, 서명이 검증된 응답만 로그인되도록 했습니다.
결과
인증 없이 통과하던 연동이 서명 검증을 거치는 실제 SSO가 되었습니다. 같은 방식을 영상 플랫폼 Panopto에도 적용했고, 설정 방법과 인증 흐름을 Confluence 문서로 남겨 개발자들과 리뷰했습니다.
