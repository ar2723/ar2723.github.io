연동 2025.07 – 09 SAML 2.0 Canvas LMS

학습 포털을 IdP로 만든 SAML SSO 연동 (Canvas · Panopto)

포털에서 과제나 퀴즈 링크를 누르면 Canvas 로그인 화면으로 넘어가고, 로그인 후에는 홈 화면으로 가 버렸습니다. 기존 연동은 인증 절차 없이 연결만 되어 있었고, 팀에 SAML을 다뤄 본 사람이 없었습니다.

구현
  • 포털 서버를 IdP, Canvas를 SP로 두는 SP-initiated 흐름을 구성했습니다.
  • Canvas가 보낸 AuthnRequest를 검증·디코딩해 속성을 추출했습니다. 응답은 Thymeleaf XML 템플릿으로 만들고, Assertion에 전자서명을 넣었습니다.
  • 서명된 응답을 Base64로 인코딩해 RelayState와 함께 자동 POST 폼으로 돌려주었습니다. 그래서 사용자가 누른 과제 상세 페이지로 바로 이동합니다.
  • 인증서와 키는 OpenSSL로 만들고, Canvas에는 인증서 지문을 등록해 응답을 검증하게 했습니다.
확장
같은 IdP를 두 번째 SP인 Panopto에도 연결했습니다. 로그인 화면을 건너뛰는 문제는 해결했고, 기존 인스턴스 계정이 연동되지 않고 새로 생성되는 제약은 원인과 운영 방안을 문서로 정리했습니다.
남긴 것
Confluence에 설정 항목별 의미, 요청·응답 XML 예시, 시퀀스 다이어그램을 남겨 개발자들과 리뷰했습니다. 미구현인 SSO 로그아웃은 토큰 무효화와 로그아웃 요청 연계, 두 가지 방안으로 제안했습니다.

2023년 팀 프로젝트를 레거시로 보고 운영 가능한 수준까지 정비

부트캠프에서 만든 북메이트를 실제 서비스처럼 단계별로 고치고 있습니다. 매 단계의 판단 근거는 문서로 남깁니다.

한 일
  • Spring Security 도입: 기본 인증 필수, 상태 변경은 POST + CSRF, 레거시 세션과의 브리지
  • Flyway로 스키마 기준선을 잡고 변경을 마이그레이션으로만 관리
  • Testcontainers(Oracle) 통합 테스트와 레거시 동작을 고정하는 특성 테스트
  • 미니PC(Ubuntu) + nginx + GitHub Actions로 master push 시 운영 배포, 배포 후 스모크 테스트
