KCP PG 정산 API 연동: 암호화된 개인키로 전자서명 만들기

복지카드 서비스에 KCP PG 정산대사 API를 연동하는 일을 맡았습니다. API를 호출할 때마다 전자서명 값을 함께 보내야 했는데, 당시에는 개인키나 인증서 개념을 잘 몰라서 많이 헤맸습니다.

과제
KCP에서 암호화된 개인키 파일(PEM)과 그 비밀번호를 받았고, 요청 데이터를 SHA256withRSA 방식으로 서명해서 보내야 했습니다.
해결
  • API 문서로 요청 규격을 확인하고, 서명을 만드는 과정을 단계별로 나눠 접근했습니다.
  • PEM 파일, 개인키 암호화, 전자서명 개념을 GPT로 먼저 정리하고, 어떤 라이브러리(Bouncy Castle)와 클래스를 써야 하는지 검색으로 확인했습니다.
  • 암호화된 개인키를 읽어 비밀번호로 풀고, Java 개인키 객체로 바꾼 뒤 서명을 만들어 Base64로 인코딩하는 모듈을 작성했습니다.
  • 디버깅하면서 단계마다 결과가 맞는지 확인했고, 모르는 부분은 개발팀장님께 물어서 확인했습니다.
결과
서명 모듈을 완성해 정산대사 API 연동을 마쳤고, 이후 연동 배치 작업을 모니터링했습니다.
남긴 것
같은 문제를 다시 겪지 않도록 서명 모듈과 개념을 블로그에 정리했습니다.
