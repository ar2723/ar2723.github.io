개인 프로젝트 2026 북메이트 리팩토링 미니PC 운영 배포

2023년 팀 프로젝트를 다시 꺼내 단계별로 고치고 직접 운영하기

부트캠프에서 만든 북메이트를 그냥 두기 아까워서, 문제점을 하나씩 고치고 실제 서버에 올려 운영해 보고 있습니다. 회사에서 레거시를 다룰 때처럼 한 번에 다 바꾸지 않고 단계를 나눠 진행합니다.

단계
  • Phase 0 · 기준 잡기: 문서와 실제 DB가 달랐던 스키마를 맞춰 Flyway로 관리하고, 코드에 있던 비밀 값을 환경변수로 뺐습니다. 이후 수정이 기존 기능을 깨지 않는지 확인할 통합 테스트도 만들었습니다.
  • Phase 1 · 보안: Spring Security로 로그인과 권한 검사를 붙이고, 데이터를 바꾸는 요청은 POST와 CSRF 보호를 거치게 바꿨습니다.
  • Phase 3 · 업그레이드: Spring Boot 2.7을 3.5로, Java를 21로 올렸습니다.
  • 다음 단계: 서비스 계층 정리(Phase 2)와 Spring Boot 4 업그레이드
운영
미니PC(Ubuntu)에 nginx로 서비스를 띄웠습니다. master에 push 하면 GitHub Actions가 자동으로 배포하고, 배포 뒤에는 스모크 테스트로 서비스가 정상인지 확인합니다.
기록
단계마다 무엇을 왜 바꿨는지 저장소의 docs/refactoring 문서로 남깁니다.
